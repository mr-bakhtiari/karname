# پرتال ساخت کارنامه مدرسه

پرتال فارسی و کاملاً سمت‌مرورگر برای تبدیل فایل نمرات دانش‌آموزان به کارنامه‌های آماده چاپ. سامانه دانش‌آموزان و درس‌ها را به‌صورت پویا از Excel می‌خواند، عکس‌ها را با کد دانش‌آموزی تطبیق می‌دهد و در هر برگه A4 دو کارنامه قرار می‌دهد.

نسخه عملیاتی: [karname.mrbakhtiari.com](https://karname.mrbakhtiari.com)

## قابلیت‌ها

- تعریف چند مدرسه، کلاس و دوره کارنامه با تنظیمات مستقل
- دریافت فایل‌های `XLSX`، `XLS` و `CSV` و اعتبارسنجی نمره‌ها
- پشتیبانی از تعداد متغیر دانش‌آموز و حداکثر ۳۲ درس
- نمایش درس‌ها در ردیف‌های ۱۶تایی و چهار جدول چهارتایی
- دریافت ZIP تصاویر و تطبیق خودکار نام فایل با کد دانش‌آموزی
- پشتیبانی از `JPG`، `PNG`، `WebP`، `TIF` و `TIFF`
- استفاده از تصویر پیش‌فرض برای دانش‌آموز فاقد عکس
- محاسبه معدل، رتبه کلاس و میانگین هر درس
- نمودار میله‌ای نمره دانش‌آموز و نمودار خطی میانگین کلاس
- پشتیبانی از نمره عددی یا توصیفی برای انضباط؛ انضباط در نمودار نمایش داده نمی‌شود
- لوگوی اختیاری مدرسه با نمایش نیمه‌شفاف روی اطلاعات سربرگ
- فونت وزیر، اعداد فارسی، چیدمان راست‌به‌چپ و خروجی PDF از مسیر چاپ مرورگر
- پردازش اکسل، نمره‌ها و تصاویر فقط در حافظه مرورگر و بدون ارسال یا ذخیره روی سرور
- تمام فونت‌ها و کتابخانه‌های زمان اجرا روی خود پروژه میزبانی می‌شوند و وابستگی CDN وجود ندارد

## اجرای محلی

پروژه Build Step ندارد و فایل‌های قابل اجرا داخل `dist` قرار دارند. از بازکردن مستقیم `index.html` با پروتکل `file://` خودداری کنید و یک وب‌سرور محلی اجرا کنید:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

سپس آدرس زیر را باز کنید:

```text
http://127.0.0.1:4173
```

## ساختار فایل اکسل

ردیف اول باید عنوان ستون‌ها باشد. ستون‌های پایه عبارت‌اند از:

| ستون | توضیح |
| --- | --- |
| کد دانش‌آموزی | بهتر است ستون اول و نوع سلول `Text` باشد |
| نام | نام دانش‌آموز |
| نام خانوادگی | نام خانوادگی دانش‌آموز |
| نظر | متن اختیاری برای نمایش روی کارنامه |
| ستون‌های درس | هر ستون ناشناخته دیگر به‌عنوان درس در نظر گرفته می‌شود |
| انضباط | آخرین ستون درس‌ها؛ عدد صحیح، اعشاری یا عبارت توصیفی |

نکات مهم:

- کد دانش‌آموزی باید یکتا باشد.
- برای حفظ صفر ابتدای کد، نوع سلول کد دانش‌آموزی را `Text` انتخاب کنید؛ مانند `۰۱۴۰۵۱۰۰۱`.
- نمره‌های عددی باید بین ۰ تا ۲۰ باشند و می‌توانند اعشاری باشند.
- نمره خالی در معدل دانش‌آموز و میانگین آن درس محاسبه نمی‌شود؛ نمره صفر محاسبه می‌شود.
- نمره‌ها گرد نمی‌شوند و فقط هنگام نمایش، در صورت نیاز، حداکثر دو رقم اعشار دارند.
- فقط ستون انضباط می‌تواند مقدار توصیفی مانند «عالی» یا «خیلی خوب» داشته باشد.
- فایل نمونه را می‌توان از مرحله «فایل نمرات» داخل سامانه دریافت کرد؛ شیت آن راست‌به‌چپ و ستون کد از نوع Text است.

## تصاویر دانش‌آموزان

همه تصاویر را در یک فایل ZIP قرار دهید. نام هر فایل باید همان کد کامل دانش‌آموزی باشد. پوشه داخلی ZIP اهمیتی ندارد.

```text
۰۱۴۰۵۱۰۰۱.jpg
۰۱۴۰۵۱۰۰۲.tiff
```

صفرهای ابتدای کد باید هم در فایل اکسل و هم در نام تصویر یکسان باقی بمانند. اگر تصویری پیدا یا خوانده نشود، آیکون پیش‌فرض نمایش داده می‌شود.

## روند ساخت کارنامه

1. از بخش «کلاس‌ها و دوره‌ها» یک کلاس جدید بسازید.
2. نام مدرسه، سال تحصیلی، پایه، دوره، شماره کلاس و سایر تنظیمات را وارد کنید.
3. در صورت نیاز لوگوی مدرسه را انتخاب کنید.
4. فایل نمرات را بارگذاری کنید و خطاهای گزارش‌شده را برطرف کنید.
5. فایل ZIP تصاویر را به‌صورت اختیاری وارد کنید.
6. پیش‌نمایش را تولید و نتیجه را بازبینی کنید.
7. از دکمه چاپ استفاده کنید و مقصد چاپ را روی «Save as PDF» یا چاپگر قرار دهید.

تنظیمات عمومی کلاس در `localStorage` همان مرورگر نگه‌داری می‌شود، اما فایل اکسل، نمره‌ها، نظرها، لوگو و عکس‌ها فقط به‌صورت موقت در حافظه مرورگر هستند.

## اجرا با Docker

پیش‌نیازها:

- Docker Engine
- Docker Compose v2
- شبکه خارجی `shajare_frontend` در استقرار فعلی

اگر شبکه هنوز وجود ندارد، یک بار آن را بسازید:

```bash
docker network create shajare_frontend
```

سپس سرویس را اجرا کنید:

```bash
docker compose up -d --build
docker compose ps
```

کانتینر Nginx روی پورت داخلی `8080` گوش می‌دهد و عمداً هیچ پورت مستقیمی روی میزبان منتشر نمی‌کند. ورودی HTTPS باید از Reverse Proxy موجود به نام شبکه‌ای `karname-web:8080` هدایت شود. این طراحی از تداخل با پروژه‌های دیگر سرور جلوگیری می‌کند.

## استقرار فعلی

فایل‌های مرتبط:

```text
Dockerfile                 تصویر Nginx کم‌دسترسی
compose.yaml               سرویس و اتصال به شبکه مشترک Reverse Proxy
deploy/nginx.conf          تنظیمات Nginx و هدرهای امنیتی
deploy/Caddyfile.karname   مسیر دامنه در Caddy سرور فعلی
deploy/remote-deploy.sh    اسکریپت به‌روزرسانی استقرار فعلی
dist/                      همه فایل‌های وب و وابستگی‌های Self-hosted
```

اسکریپت `deploy/remote-deploy.sh` برای معماری سرور فعلی نوشته شده است. پیش از استفاده روی سروری دیگر، مسیر نصب، نام کانتینر Caddy و نام شبکه Docker را با محیط مقصد تطبیق دهید. هیچ رمز، کلید یا توکن نباید داخل مخزن قرار گیرد.

## معماری و حریم خصوصی

- برنامه یک وب‌اپ استاتیک است و Backend یا پایگاه داده برای اطلاعات دانش‌آموزان ندارد.
- Excel با کتابخانه محلی SheetJS در مرورگر خوانده می‌شود.
- ZIP با JSZip و TIFF با UTIF، هر دو از فایل‌های محلی پروژه، پردازش می‌شوند.
- عکس‌ها با Object URL موقت نمایش داده می‌شوند و به سرور ارسال نمی‌شوند.
- تولید PDF از موتور چاپ مرورگر انجام می‌شود.
- وب‌سرور داخل کانتینر با کاربر غیرریشه، فایل‌سیستم فقط‌خواندنی و بدون Capability اضافی اجرا می‌شود.

## عیب‌یابی

- اگر فونت یا کتابخانه‌ها بارگذاری نشدند، پروژه را از طریق HTTP اجرا کنید و وجود فایل‌های `dist/fonts` و `dist/vendor` را بررسی کنید.
- اگر صفر ابتدای کد حذف شد، ستون کد دانش‌آموزی را در Excel به `Text` تبدیل و مقدار را دوباره وارد کنید.
- اگر عکس تطبیق داده نشد، پسوند مجاز و برابری دقیق نام فایل با کد داخل Excel را بررسی کنید.
- اگر دکمه پیش‌نمایش فعال نیست، خطاهای مرحله فایل نمرات یا تنظیمات ضروری کلاس را اصلاح کنید.
- اگر چیدمان چاپ درست نیست، کاغذ را A4، مقیاس را ۱۰۰٪ و حاشیه‌های مرورگر را روی حالت پیش‌فرض یا None قرار دهید.

## توسعه

تغییرات رابط در این فایل‌ها انجام می‌شود:

- `dist/index.html`: ساختار صفحات و فرم‌ها
- `dist/app.css`: ظاهر، واکنش‌گرایی و قواعد چاپ
- `dist/app.js`: خواندن Excel و ZIP، محاسبات و تولید کارنامه

پس از هر تغییر، حداقل سناریوهای زیر را بررسی کنید:

- کد دانش‌آموزی با صفر ابتدایی
- نمره خالی در برابر نمره صفر
- نمره اعشاری و انضباط توصیفی
- بیش از ۱۶ درس
- عکس TIFF و دانش‌آموز بدون عکس
- دو کارنامه در هر صفحه A4 و ذخیره PDF

این مخزن در حال حاضر فایل مجوز مستقل ندارد؛ استفاده و انتشار آن تابع تصمیم مالک مخزن است.
